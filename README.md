# ureatoammoniacalculator

I am happy to share that Version 1.0 of the Urea to Ammonia Calculator web app is now live as of 7:30 PM on Thursday, 8 October 2026.

It is now available for everyone to use. Given the land area and the urea quantity, it calculates:

1.	Land area in acres
2.	Nitrogen quantity (Kg)
3.	Required NH₃ quantity (Kg)
4.	N flow rate input for the controller (Kg/Acre)
5.	Number of cylinders required for application

Please feel free to share it with the team. If anyone runs into an issue or has suggestions for improvement, they can reach out to me directly. I would be happy to incorporate them in the next version.
